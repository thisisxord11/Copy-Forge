# Copyforge — AI Content Studio (Fast, Keyless Version)

A single HTML file. No API key, no backend, no local model download. Real Claude runs in the cloud, called through **Puter.js** — a free, keyless AI gateway.

## How it works

- The site loads `https://js.puter.com/v2/`, a free library that gives browser apps direct access to Claude, GPT, Gemini and 400+ other models — with no API key for you to manage.
- Puter uses a "User-Pays" model: the person using the site covers their own usage through a free Puter account. You never pay, never see a bill, and never handle a key.
- Responses stream in live, just like a normal AI chat.

## What to expect the first time

- The **first time a visitor clicks Generate**, Puter may show a **quick sign-in popup** (free Puter account — a few seconds, one time). This is normal — it's how Puter knows whose free usage to count, since there's no API key involved at all.
- After that first sign-in, generations are fast — real Claude speed, not local-device speed.

## Deployment

Just `index.html`. Upload it to GitHub → Vercel (or Netlify, GitHub Pages, anywhere) exactly like before. No environment variables, no settings, nothing else to configure.
